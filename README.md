# ECSE 4320 — Advanced Computer Systems

Completed class projects profiling SIMD, cache and memory, and SSD performance. Each project includes its implementation, experimental results, figures, and report.

## Projects

| Project name | Directory | Report |
| --- | --- | --- |
| Project 1: SIMD Advantage Profiling | [proj1](proj1/) | [Report](proj1/report.md) |
| Project 2: Cache & Memory Performance Profiling | [proj2](proj2/) | [Report](proj2/report.md) |
| Project 3: SSD Performance Profiling | [proj3](proj3/) | [Report](proj3/report.md) |

Code and build, run, and analysis scripts are in each project directory. Project 1 keeps raw data, compiler/disassembly evidence, processed data, and figures in `proj1/results/r1/`; Project 2 keeps raw data in `proj2/data/` and processed data and figures in `proj2/results/`; Project 3 keeps fio configurations, raw and processed data, and figures in `proj3/results/`.

## AI Use

OpenAI Codex (GPT Sol model) was used throughout all three projects to assist with code generation, debugging, scripting, data processing, and report formatting.

I primarily focused on implementing the core C++ benchmark functionality, things like the computational kernels. AI assistance was used more extensively to generate supporting code, including experiment automation scripts, correctness checks, data analysis scripts, and plotting utilities. AI-generated code was reviewed and modified as needed to meet project requirements and achieve the intended functionality.

For the reports, I independently examined the experimental results, interpreted performance trends, and developed the technical conclusions. AI was primarily used to help organize, format, and improve the presentation of the reports.
